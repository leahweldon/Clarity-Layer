# Contributions

Clarity Layer was built by Team Kojack for CS7IS5 Adaptive Applications at Trinity College Dublin (February–April 2026). The team met weekly, planned in Jira and developed on feature branches with pull requests. The design, report and presentation were joint work; the summary below covers each member's main areas in the code, based on the commit history.

| Contributor | Main areas |
|---|---|
| **Leah Weldon** | Repository setup; the front-end proof of concept the app grew from (onboarding, document input, reading workspace, scrutability side panel, session summary); reader layout, reading progress, collapsible side panel and consistent theming; project README |
| **Liam Byrne** | PDF upload and Clerk sign-in with the protected user flow; personal dictionary; final rework of adaptive prompts, nudges and the session summary |
| **Petra Marcokova** (team lead) | Persona presets; session summary page; onboarding preview |
| **Martha Ryan** | Glossary for predefined documents; adaptive prompt triggers and messages; nudge fixes; explanations for reading goals in onboarding |
| **Tanmay Birari** | Adaptive-prompt logging prototype for the *Why* tab, *Your Model* section and session log |

The project report is in [docs/Clarity-Layer-Final-Report.pdf](docs/Clarity-Layer-Final-Report.pdf).
